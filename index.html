Modular AI Multi-Agent Platform

Bachelor's Thesis · September 2026 – Present · In Development

Design and prototypical implementation of a modular, event-driven multi-agent platform for Ambient Assisted Living (AAL), aimed at supporting older adults in their everyday lives.

PythonLangChainSQLitepytest
Project details

Agents communicate indirectly through a shared event bus, subscribe to relevant events and propose actions. A central coordination component evaluates these proposals against predefined rules and executes approved actions. The architecture supports runtime replacement of agents, sensors and actuators, as well as configurable large language models through LangChain.

Implemented use cases

  • Medication reminders with user feedback and persistent schedule adjustments
  • Motion-triggered hallway lighting at night
  • Test notifications triggered by simulated fall detection events
  • On-demand summaries of recorded events

Technical highlights

  • Modular and event-driven software architecture
  • Runtime replacement of system components
  • Rule-based action coordination
  • Prevention of redundant lighting commands
  • Persistent application state across restarts
  • Automated testing and scenario-based validation

Technologies: Python, LangChain, SQLite, pytest

LLMs used in prototype testing: Qwen, Gemini

AI-Assisted PC Price Evaluation Tool

Personal Project · Local Prototype

Development of a web-based application that estimates the value of used desktop computers listed on Kleinanzeigen by comparing individual hardware components with current eBay listings.

PythonFastAPISQLAlchemyGroq API
Project details

The user submits a listing URL, reviews the automatically identified hardware components and initiates a price evaluation. The application uses an LLM to extract hardware specifications and suggest component conditions and search terms. Price estimates are calculated independently of the AI using the median of matching listing prices, including shipping costs. Estimated component values are added together to estimate the overall system value.

The backend is built with FastAPI, integrating listing extraction, AI-assisted analysis, marketplace queries and price calculations. A local web interface allows users to review the extracted information before starting the evaluation.

Technical highlights

  • Web scraping and extraction of unstructured listing data
  • LLM-based hardware identification using the Groq API
  • Integration of the eBay Browse API
  • Hardware name normalisation and model-specific search filtering
  • Deduplication of marketplace listings using item IDs
  • Deterministic, median-based price estimation
  • Local web interface and database integration

Technologies: Python, FastAPI, Beautiful Soup, Jinja2, SQLAlchemy, SQLite, Groq API, eBay Browse API

LLM: GPT-OSS-20B
